## ✨ About the Game

**Hospital Tycoon: Life and Care** is an ambitious hospital management simulation project focused on combining 3D environments, interactive gameplay, and healthcare management.

The goal is to create an engaging virtual hospital where players can experience the challenges and responsibilities of running a healthcare institution.

### 🎯 Project Vision

- 🏥 Build and expand a modern hospital.
- 🩺 Manage healthcare facilities and medical services.
- 👨‍⚕️ Create an immersive hospital environment.
- 🚑 Develop interactive hospital management systems.
- 🌍 Experience a detailed 3D simulation world.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd hospital-tycoon-life-and-care
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 5. Build for Production

```bash
npm run build
```

### 6. Preview Production Build

```bash
npm run preview
```
